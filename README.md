# scripts

Shell scripts served as tools by [scripts-mcp](https://github.com/harsig/scripts-mcp). Each script describes its tool in a metadata header; see the scripts-mcp README for the format.

| Script | Tool |
| --- | --- |
| `date.sh` | `date`: the current date and time, optionally in another time zone (`timezone`) and format (`format`: `iso`, `rfc`, `date`, `time`, `unix`). Needs GNU `date`. |
